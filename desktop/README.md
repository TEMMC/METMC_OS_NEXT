# METMC OS NEXT Desktop

Native Android desktop inspired by GNOME Shell concepts. It does not embed GNOME/Mutter and does not require X11, VNC, or Termux:X11.

Shell areas: top panel, Activities/Overview, app launcher/search, workspaces, native window cards, taskbar, quick settings, notifications, settings, browser/terminal launch, and updater.

GNOME Shell is GPL-2.0-or-later. This project uses its public architecture and behavior as a reference rather than embedding its runtime.
